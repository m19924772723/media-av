# 视频转码与处理 · 简介

> 用 ffmpeg 做转码、剪辑、压缩与格式转换

## 能做什么

- 格式转换与压缩
- 裁剪拼接与合并
- 加水印 / 字幕
- 批量处理
- 提取音频 / 帧

## 适合的项目

- **视频压缩**：减小体积
- **格式统一**：素材整理
- **批量转码**：流水线

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：ffmpeg 9.0.1、ffprobe（已就绪）、Python / Node 封装
- 注意：本机 ffmpeg 已就绪；CPU 转码较慢，长视频注意耗时

## 快速开始

```bash
ffmpeg -i in.mp4 -c:v libx264 -crf 23 out.mp4
ffprobe -v error -show_format in.mp4
ffmpeg -i in.mp4 -ss 00:00:03 -vframes 1 cover.png
```
