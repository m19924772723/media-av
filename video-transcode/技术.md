# 视频转码与处理 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 引擎 | ffmpeg | 全能媒体工具 |
| 信息 | ffprobe | 媒体元数据 |
| 封装 | Python / Node | 批量编排 |
| 模板 | 参数预设 | 质量一致 |
| 工具 | HandBrake（可选） | 图形化转码 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **容器 vs 编码**：mp4 / mkv 与 h264 / h265
- **码率控制**：CRF 与目标码率
- **滤镜链**：scale / crop / 字幕
- **批量处理**：遍历与命名

## 学习路径

1. 先做一次格式转换
2. 再学压缩与滤镜
3. 最后做批量流水线
