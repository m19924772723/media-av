# 图像处理与批处理 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 图像 | Pillow | 读写与变换 |
| 数值 | numpy | 像素操作 |
| 抠图 | rembg | 去背景 |
| 命令行 | ImageMagick | 批量转换 |
| 媒体 | ffmpeg | 抽取与缩放 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **色彩模式**：RGB / RGBA / P
- **压缩质量**：JPEG quality 与体积
- **缩放算法**：LANCZOS 质量较好
- **批量命名**：输出规则统一

## 学习路径

1. 先做单图压缩与裁剪
2. 再批量化加水印
3. 最后做智能压缩到目标体积
