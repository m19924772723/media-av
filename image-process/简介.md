# 图像处理与批处理 · 简介

> 图像批量处理、压缩与水印

## 能做什么

- 批量压缩 / 裁剪 / 旋转
- 加水印
- 格式转换
- 自动抠图
- 生成缩略图

## 适合的项目

- **素材批处理**：配图压缩
- **公众号配图**：体积达标
- **缩略图**：统一规格

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：Pillow / numpy（需装）、ffmpeg（已就绪）、ImageMagick（可选）
- 注意：批量处理输出到新目录，保留原图

## 快速开始

```bash
pip install pillow
python squeeze.py ./in ./out --max-kb 500
# 输出压缩后的图片
```
