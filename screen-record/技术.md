# 录屏与设备投屏 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 录屏 | ffmpeg gdigrab / OBS | 桌面采集 |
| 投屏 | scrcpy / adb | 安卓镜像 |
| 推流 | ffmpeg / OBS | RTMP |
| 自动化 | 脚本调度 | 定时录制 |
| 合成 | ffmpeg | 多源合成 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **采集源**：桌面、窗口、区域
- **编码参数**：帧率与码率
- **推流协议**：RTMP / SRT
- **自动化**：定时与触发

## 学习路径

1. 先录一段桌面视频
2. 再学投屏与推流
3. 最后做定时自动录制
