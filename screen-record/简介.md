# 录屏与设备投屏 · 简介

> 录屏、投屏与设备画面采集

## 能做什么

- 桌面录屏
- 手机投屏
- 多设备画面采集
- 直播推流
- 自动分段录制

## 适合的项目

- **教程录制**：演示步骤
- **投屏操控**：手机远控
- **过程留痕**：自动录制

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：ffmpeg gdigrab（已就绪）、scrcpy（可选）、OBS（可选）、Android SDK/adb（已装）
- 注意：本机 ffmpeg 与 adb 就绪，可组合实现录屏与投屏

## 快速开始

```bash
ffmpeg -f gdigrab -i desktop -t 10 out.mp4
scrcpy --record demo.mp4
# 或用 OBS 录制
```
