# 动效与程序化渲染 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 数学动画 | Manim | 公式与几何 |
| 前端动画 | Remotion / Motion Canvas | 代码驱动 |
| 逐帧 | Pillow + ffmpeg | 完全可控 |
| 矢量 | Lottie / Rive | 轻量动效 |
| 模板 | 参数化 | 批量变体 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **时间轴**：关键帧与插值
- **缓动曲线**：自然动效
- **逐帧合成**：帧率与时长
- **参数化**：模板 + 变量

## 学习路径

1. 先做一个简单动画
2. 再学缓动与编排
3. 最后做参数化模板
