# 动效与程序化渲染 · 简介

> 程序化生成动效、图表动画与视频

## 能做什么

- 数据动画与动态图表
- 数学 / 讲解动画
- 片头片尾
- 参数化模板
- 自动渲染

## 适合的项目

- **科普动画**：讲解演示
- **数据视频**：图表动态
- **教学演示**：概念可视化

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：Pillow + ffmpeg（已就绪）、Manim / Remotion（需装）、Lottie
- 注意：本机可做逐帧渲染；复杂 3D 渲染受硬件限制

## 快速开始

```bash
pip install manim
manim -pql scene.py MyScene
# 或用 ffmpeg 合帧
```
