# 字幕与语音转写 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 识别 | Whisper / faster-whisper | 本地离线 |
| 音频 | ffmpeg | 抽取与切分 |
| 分段 | VAD | 静音切分 |
| 翻译 | 翻译 API | 双语字幕 |
| 输出 | SRT / VTT | 字幕格式 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **模型大小**：速度与精度权衡
- **语音活动检测**：分段更准
- **时间轴**：字幕与音频对齐
- **字幕格式**：SRT / VTT / ASS

## 学习路径

1. 先把一段音频转成文字
2. 再加时间轴与分段
3. 最后做批量与翻译
