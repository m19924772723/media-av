## 使用建议

1. **先跑通再读码**：把项目跑起来，用一遍再回头看实现
2. **带着问题读**：聚焦「它怎么解决某个难点」，而不是逐行通读
3. **小步借鉴**：先抄一个模块的思路，再考虑整体架构
4. **注意许可**：商用前确认开源协议（MIT / Apache-2.0 / AGPL 差异很大）
