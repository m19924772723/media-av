# 字幕与语音转写 · 简介

> 语音转写与字幕生成

## 能做什么

- 音视频转文字
- 自动打轴（时间戳）
- 字幕翻译
- 批量转写
- 会议纪要

## 适合的项目

- **视频字幕**：内容发布
- **会议记录**：纪要整理
- **访谈整理**：文字稿

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：Whisper / faster-whisper（需装）、ffmpeg（已就绪）
- 注意：本地离线转写免费且隐私友好；长音频耗时较长

## 快速开始

```bash
pip install faster-whisper
python transcribe.py audio.mp3
# 输出 srt 字幕
```
