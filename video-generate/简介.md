# 视频自动生成 · 简介

> 分镜 / 图文驱动的自动化视频生成

## 能做什么

- 图文成片
- 分镜驱动渲染
- 口播 / 配音合成
- 批量短视频
- 自动字幕

## 适合的项目

- **知识科普**：图文视频
- **口播短视频**：批量产出
- **批量内容生产**：流水线

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：ffmpeg + Pillow（已就绪）、TTS、Python；本机已有分镜工作流
- 注意：本机已有 video-pipeline（JSON 分镜 → 逐帧 → 视频）可复用

## 快速开始

```bash
python gen.py storyboards/demo.json
# 或复用本机 run.cmd storyboards/demo.json
```
