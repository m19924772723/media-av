# 视频自动生成 · 开发计划

> 原则：**每个阶段都产出可运行、可验证的东西**，先小步跑通再逐步加深。

## 阶段一 · 单场景

- **目标**：跑通
- **产出**：一张图 / 一段视频

- [ ] Pillow 出帧
- [ ] ffmpeg 合成
- [ ] 预览效果

## 阶段二 · 多场景

- **目标**：成片
- **产出**：完整分镜视频

- [ ] 分镜 JSON
- [ ] 场景串联
- [ ] 转场效果

## 阶段三 · 配音字幕

- **目标**：更好看
- **产出**：带配音的视频

- [ ] TTS 配音
- [ ] 自动字幕
- [ ] 音画对齐

## 阶段四 · 批量

- **目标**：可交付
- **产出**：批量生产流水线

- [ ] 模板化
- [ ] 批量生成
- [ ] 质量校验

| 阶段 | 验收标准 |
