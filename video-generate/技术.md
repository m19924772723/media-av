# 视频自动生成 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 渲染 | ffmpeg + Pillow | 逐帧合成 |
| 分镜 | JSON 配置 | 结构化驱动 |
| 配音 | TTS API | 语音合成 |
| 字幕 | Whisper / SRT | 自动字幕 |
| 模板 | 代码生成视频 | 可编程 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **分镜数据结构**：场景、文本、时长
- **版式缩放**：不同分辨率适配
- **音画同步**：字幕与配音对齐
- **批量生成**：模板 + 变量

## 学习路径

1. 先渲染一个单场景视频
2. 再串成多场景
3. 最后加配音与批量
