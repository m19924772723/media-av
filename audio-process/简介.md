# 音频处理与合成 · 简介

> 音频处理、降噪与语音合成

## 能做什么

- 格式转换与裁剪
- 降噪与音量均衡
- 语音合成（TTS）
- 人声分离
- 背景音乐处理

## 适合的项目

- **播客处理**：剪辑降噪
- **配音生成**：批量语音
- **音频剪辑**：铃声 / 素材

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：ffmpeg（已就绪）、pydub / librosa（需装）、TTS（需装 / API）
- 注意：本机 ffmpeg 已就绪；高质量 TTS 建议走 API

## 快速开始

```bash
ffmpeg -i in.wav -af "volume=1.5" out.wav
pip install pydub
python audio.py ./in ./out
```
