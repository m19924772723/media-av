# 音频处理与合成 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 处理 | ffmpeg | 编解码与滤镜 |
| Python | pydub / librosa | 音频分析 |
| 合成 | TTS API / 本地 | 语音生成 |
| 分离 | Demucs | 人声伴奏 |
| 工具 | SoX | 处理套件 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **采样与位深**：音频质量基础
- **响度标准**：LUFS 与均衡
- **降噪**：谱减与滤波
- **TTS 参数**：音色、语速、停顿

## 学习路径

1. 先做格式转换与裁剪
2. 再学降噪与均衡
3. 最后做 TTS 与批量
